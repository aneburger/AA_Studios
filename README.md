Game Title: MarshRooms!
------------------------

1. Running the game:
Double click on the MarshRooms!.exe file to open the game.
-----------------------
2. Starting the game:
Click the Tutorial button on the title page to get an introduction to the gameplay, narrative and controls.
Click the New Game button on the title page to play the game starting at Floor 1.
Use the Options menu to change the Music and Sound Effects volumes.
-----------------------
3. Accessing the Cheats Panel:
The Cheats panel contains several controls that allow 
markers to progress through the game with ease.

To access it, open the in-game Pause Menu and navigate to the Options menu. 
Then, toggle the “Open Cheats” button located below the Options menu to open the Cheats panel.
